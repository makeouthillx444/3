# Трекер привычек

Небольшое консольное приложение на Python для создания привычек, ежедневных отметок и просмотра статистики.

<div align="center">
  
**Создатели проекта:** Богачёв Артём Волосович Андрей, Дунаев Дмитрий, Кырбоба Дарья.

</div>

## Модули

1. **Habit Manager** (`habit_service.py`) — создание, просмотр, архивирование и удаление привычек.
2. **Check-in** (`checkin_service.py`) — отметки «выполнено/пропущено» и заметки за день.
3. **Streak & Statistics** (`statistics_service.py`) — текущая серия, лучший стрик и процент выполнения за выбранный период.
4. **Notification & Storage** (`storage_service.py`) — сохранение данных в `habits.json` и список напоминаний на сегодня.

## Запуск

Нужен Python 3.9 или новее. Дополнительные библиотеки не требуются.

```bash
python main.py
```

## Запуск тестов

```bash
python test_runner.py
```

## Важные замечания

- Напоминания пока отображаются списком в приложении; push-уведомления не отправляются.
- Данные хранятся локально в JSON-файле.
- Для негативного тестирования предусмотрены проверки пустого названия, неправильной периодичности, несуществующего ID и некорректного числа дней.

## Пример Bug Report

| ID | Модуль / метод | Входные данные | Ожидаемый результат | Результат после исправления |
|---|---|---|---|---|
| BUG-01 | `HabitService.add_habit` | Пустое название `""` | Ошибка валидации | `ValueError`, пустая привычка не создаётся |
| BUG-02 | `StatisticsService.success_rate` | `days=0` или `days=-2` | Ошибка валидации | `ValueError`, расчёт не выполняется |
| BUG-03 | `CheckinService.mark` | ID `999`, которого нет | Сообщение об ошибке | `ValueError`, отметка не создаётся |
