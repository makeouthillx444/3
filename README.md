# ReceiptModule

## Задача
Как кассиры, мы хотим сформировать чек с расчётом стоимости блюд, налога и общей суммы.

## Архитектура клиент-сервер

```text
Клиент
  |
  | отправляет список блюд
  v
Сервер
  |
  | вызывает ReceiptModule
  v
ReceiptModule
  |
  | возвращает готовый чек
  v
Сервер -> Клиент
```

## Файлы
- `receipt.py` — код модуля чека.
- `test_runner.py` — тестирование модуля.
- `BUG_REPORT.md` — найденные ошибки.

## Запуск

```bash
python test_runner.py
```

По умолчанию налог составляет 20%.
